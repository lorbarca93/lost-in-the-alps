Source blend

  • Refuges.info - 5,250 huts in French Alps
  • Mountainhuts.info - 1,343 huts across Europe
  • Boudy.info - 889 huts in the Alps region
  • Mountain-huts.net - 660 huts in the Balkans

Data access

  • SQLite database: data/mountain_huts.db
  • API endpoints: website/api/stats.json & huts.json
  • Interactive map: mountain_huts_map.html
  • Full documentation in docs/ folder

Quality checks

  • Automatic deduplication across coordinates and name variants
  • Elevation sanity checks via SRTM-30 terrain models
  • Manual review queue for newly reported huts

Stay in the loop

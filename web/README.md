# Lost in the Alps - Mountain Huts Explorer

An interactive web map to discover and explore over 7,400 mountain huts across Europe. Plan your next alpine adventure with detailed information, real-time weather, and advanced filtering tools.

🌐 **Live Website**: [https://lorbarca93.github.io/lost-in-the-alps/](https://lorbarca93.github.io/lost-in-the-alps/)

## 🎯 Purpose

Lost in the Alps brings together comprehensive data about mountain huts, refuges, and shelters across the European Alps and beyond. Whether you're planning a weekend hike, a multi-day trek, or just exploring the alpine network, this tool helps you find the perfect mountain hut for your adventure.

## ✨ Features

### 🗺️ Interactive Map
- **7,400+ mountain huts** across 41 countries
- **7 map layers**: Topographic, Satellite, Outdoor, Humanitarian, Relief, Light, and OpenStreetMap
- **Cluster markers** for easy navigation at different zoom levels
- **Mobile-responsive** design for use on any device

### 🔍 Smart Search & Filtering
- **Fuzzy search** with autocomplete - find huts by name, country, or region
- **Advanced filters**:
  - Filter by country (41 countries available)
  - Filter by hut type (Mountain hut, Bivouac, Unmanned cabin, Shelter)
  - Filter by altitude range
  - Filter by capacity
  - Filter by contact information availability
- **Real-time statistics** showing visible huts, average altitude, and country distribution

### ⭐ Favorites System
- **Save your favorite huts** for quick access
- **Export favorites** as JSON or GPX files
- **Import favorites** from previous sessions
- **GPX export** for use with GPS devices and hiking apps

### 📍 Detailed Information
- **Complete hut details** including:
  - Name, location, and altitude
  - Contact information (phone, email, website)
  - Owner and manager details
  - Opening hours and seasons
  - Capacity information
  - Water source availability
  - Access information
- **Real-time weather** for each hut location
- **Nearby huts** - discover other huts within 20km radius

### 🌤️ Weather Integration
- **Current weather conditions** for each hut
- Powered by OpenWeatherMap API
- Temperature, conditions, and forecast information

### 📊 Statistics Dashboard
- **Live statistics** showing:
  - Total visible huts
  - Average altitude
  - Countries represented
  - Data coverage

### 📥 Export Functionality
- **Export filtered results** as KML/KMZ files
- **Export favorites** as JSON or GPX
- Perfect for planning routes in other applications

## 🚀 Getting Started

### Using the Website

1. **Visit the website**: [https://lorbarca93.github.io/lost-in-the-alps/](https://lorbarca93.github.io/lost-in-the-alps/)
2. **Explore the map**: Zoom, pan, and click on markers to see hut details
3. **Search for huts**: Use the search bar to find specific huts
4. **Filter results**: Use the sidebar filters to narrow down your search
5. **Save favorites**: Click the ⭐ button on any hut to save it
6. **Export data**: Use the export buttons to download your results

### Tips for Best Experience

- **Use filters** to find huts matching your criteria (altitude, country, type)
- **Check weather** before planning your trip
- **Save favorites** to build your personal hut collection
- **Export to GPX** to use with your GPS device or hiking app
- **Explore nearby huts** to discover alternative options

## 📊 Data Sources

The mountain hut data is collected from multiple trusted sources:
- **refuges.info** - French Alpine refuges (5,250 huts)
- **mountainhuts.info** - Europe-wide database (1,343 huts)
- **boudy.info** - Alps region (889 huts)
- **mountain-huts.net** - Balkans region (660 huts)

All data is regularly updated and verified for accuracy.

## 🛠️ Technical Details

- **Static Website**: No server required, runs entirely in the browser
- **Fast Performance**: Optimized clustering and chunked loading
- **Modern Technologies**: Leaflet.js for mapping, Fuse.js for search
- **Security**: SRI hashes on all external resources
- **Accessibility**: WCAG compliant design
